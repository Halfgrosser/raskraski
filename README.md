# «Осторожно, раскрашено!» Hiatus Chart

Интерактивная недельная карта выпусков и пауз подкаста по данным публичного RSS Podster.

## Запуск

```sh
npm run dev
```

Откройте <http://localhost:4173>.

## Обновление данных

```sh
npm run sync
```

Команда загружает `https://podster.fm/rss.xml?pid=26502` и обновляет `data/episodes.js`.
Из описаний сохраняются только названия обсуждаемых комиксов: таймкоды, вступления,
благодарности и ссылки отбрасываются.

Для повторной обработки локально сохранённого RSS:

```sh
SYNC_RSS_FILE=/path/to/feed.xml npm run sync
```

## Статическая сборка

```sh
npm run build
```

Готовые файлы появятся в `dist` и подходят для публикации на GitHub Pages.
